# 02. RoadCode

**RoadCode** is the end-to-end coding, building, debugging, hosting, deployment, and technical guidance product.

It is not just a code editor. It is the product that answers: “Okay, the code exists — now what?” It should help the user understand what a project needs next: domain, database, backend, frontend, environment variables, Cloudflare, Vercel, Railway, local server, Pi, SSH, Git, tests, logs, deployment, rollback, and ongoing maintenance.

RoadCode should fix the GitHub traffic-jam problem. Instead of endless issues, branches, PR confusion, and overlapping agents, RoadCode should route work through:
- the 172-step process
- the 17,290 master index
- the 1,729 capability layer
- the 27 agents
- RoadChain receipts
- RoadMap status

RoadCode should be able to:
- inspect a repo
- explain what exists
- identify what is missing
- plan a patch
- route the patch to the correct agent/capability
- run safe checks
- explain how to deploy
- record what changed
- avoid fake completion claims

**Primary integrations:**
- RoadOS as the shell
- RoadTrip as solo agent workspace
- CarPool for group development
- RoadChain for receipts
- HighWay for infra/deploy
- CarKeys for secrets/permissions
- RoadMap for progress
- GloveBox for capability catalog

**Core promise:**
“From idea to running system, without the ‘now what?’ cliff.”

**Status:** Canon-ready (Level 4). Implementation planned.
