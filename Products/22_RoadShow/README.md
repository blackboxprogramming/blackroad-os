# 22. RoadShow

**RoadShow** is TV Guide meets YouTube curation.

It is playlists, programming blocks, channels, public shows, shared media lineups, and creator programming.

If BlackBoard creates the video or visual media, RoadShow is where it can become a show, channel, block, or public curated experience.

**Primary integrations:**
- RoadOS for discovery and viewing
- BlackBoard for content creation
- RoadStream for unified streaming
- RoadChain for curation provenance
- BackRoad for social sharing of shows

**Core promise:**
Turn creations into curated public experiences with ownership and context.

**Status:** Canon-ready (Level 4). Implementation planned.
