# 24. GloveBox

**GloveBox** is the capabilities, meta-info, tools, saved pocket items, references, and utility layer.

CarKeys is the key; GloveBox is what the key unlocks.

It stores what BlackRoad can do, what tools exist, which capabilities are available, and what tiny saved objects or references support the rest of the system.

**Primary integrations:**
- RoadOS command surface
- RoadTrip and CarPool for agent capability access
- All products for capability discovery
- RoadMap for capability status

**Core promise:**
Know what you can do and have the tools ready.

**Status:** Canon-ready (Level 4). Implementation planned.
