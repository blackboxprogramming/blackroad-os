# 01. RoadOS

**RoadOS** is the browser-native BlackRoad computer.

It is not just a website and not just a decorative Windows 95 skin. It is the one-tab operating environment where the user’s files, terminal, agents, memory, APIs, dashboards, command palette, routes, receipts, and active work all stay together.

RoadOS exists because normal computers punish people for not knowing exact commands, folders, paths, install steps, terminal syntax, or app boundaries. A normal shell says “command not found.” RoadOS should instead infer intent, explain what happened, offer safe next actions, and remember what the user was trying to do.

RoadOS should feel like:
- your desktop
- your terminal
- your command center
- your file surface
- your AI workspace
- your memory map
- your browser computer

RoadOS must avoid:
- scattering work across random tabs
- making users install five extra apps before they can start
- leaking context between tools
- pretending the user knows infrastructure paths already
- becoming only a fake desktop with no operating logic

**Primary integrations:**
- RoadCode for building
- RoadTrip for solo AI work
- CarPool for human + AI group work
- RoadView for search
- RoadChain for receipts
- CarKeys for identity and permissions
- GloveBox for capabilities
- HighWay for infrastructure

**Core promise:**
“Open one tab. Your road is still there.”

**Status:** Canon-ready (Level 4). Implementation planned.
**MVP:** Route a command/intent to the right product/file/action and give a safe next step.
**Risk:** File/system actions require approval.
