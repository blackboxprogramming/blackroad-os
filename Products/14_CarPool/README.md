# 14. CarPool

**CarPool** is human + AI group collaboration.

RoadTrip is one operator with agents; CarPool is multiple humans with agents.

It should support project rooms, conversations, shared tasks, meetings, video/Zoom/Teams-like features through open-source alternatives where possible, and automatic note capture into RoadWire.

**Primary integrations:**
- RoadOS as the collaboration surface
- RoadTrip for agent handoffs into group rooms
- RoadWire for durable notes and decisions
- RoadMap for shared task tracking
- RoadChain for decision receipts
- CarKeys for room permissions

**Core promise:**
Group work with humans and agents that stays organized and receipted.

**Status:** Canon-ready (Level 4). Implementation planned.
