# 18. HighWay

**HighWay** is the infrastructure and high-throughput layer of BlackRoad OS.

It covers compute, routing, cloud, fleet, nodes, domains, TLS, model serving,
observability, local hardware, Pi clusters, and deployment roads — plus the
hybrid mesh backbone (Meshtastic LoRa radio mesh + Headscale/WireGuard IP
overlay) with intelligent network hopping, Git-native sync, and RoadChain
provenance.

It is the physical + virtual "road" that makes the rest of BlackRoad OS work
across disconnected and local environments.

**Status:** Canon-ready. Implementation planned.
**MVP:** scope the hybrid-mesh integration plan and a first batch pipeline.
