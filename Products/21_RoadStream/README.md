# 21. RoadStream

**RoadStream** is the wrapper for all streaming services.

Netflix, Hulu, Peacock, Prime, Disney+, Discovery+, and whatever else should be remembered and curated in one place. RoadStream solves the “where was I watching that?” problem and gives users one cross-platform viewing surface.

**Primary integrations:**
- RoadOS for unified viewing
- RoadShow for programming and curation
- RoadChain for viewing history and rights

**Core promise:**
One place for all your streaming with memory and continuity preserved.

**Status:** Canon-ready (Level 4). Implementation planned.
