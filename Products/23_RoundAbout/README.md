# 23. RoundAbout

**RoundAbout** is preparation around where someone is going.

Travel, service calls, home maintenance, sales routes, errands, job routes, before/after checklists, required materials, and context all belong here.

It handles what must be ready around the trip, not the actual route itself.

**Primary integrations:**
- RoadOS for planning surface
- Detour for execution handoff
- RoadMap for readiness tracking
- RoadChain for preparation receipts

**Core promise:**
Be prepared. Know what you need before you go.

**Status:** Canon-ready (Level 4). Implementation planned.
