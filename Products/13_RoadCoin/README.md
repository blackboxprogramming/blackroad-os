# 13. RoadCoin

**RoadCoin** is the internal credit, usage, contribution, and reward layer.

It is not money, not an investment, not a speculative coin, and not a bank. It should meter compute, unlock access, reward contribution, and connect usage to value inside the ecosystem, with extremely careful language and compliance review.

The canon explicitly says RoadCoin should be treated as an internal credit/reward layer, not a financial product.

**Primary integrations:**
- RoadOS for usage display
- RoadTrip / CarPool for agent usage tracking
- RoadWork for business usage
- RoadMap for contribution visibility
- RoadChain for usage receipts

**Core promise:**
Fair internal metering and rewards without crossing into financial product territory.

**Status:** Canon-ready (Level 4). Implementation planned.
**Risk:** High — requires strict compliance language and Portia/Atticus review.
