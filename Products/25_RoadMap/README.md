# 25. RoadMap

**RoadMap** is the progress dashboard.

It is the Salesforce-style report surface for everything being worked on: initiatives, blockers, statuses, updates, continuation points, milestones, and “oh my God, this needs attention” items.

RoadMap makes the whole operating system legible.

**Primary integrations:**
- RoadOS for the main dashboard surface
- All products for status and progress handoff
- RoadChain for proof-linked status
- RoadWire for async updates

**Core promise:**
See the whole road clearly — what’s moving, what’s blocked, and what needs attention.

**Status:** Canon-ready (Level 4). Implementation planned.
