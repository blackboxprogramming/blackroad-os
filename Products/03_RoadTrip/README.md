# 03. RoadTrip

**RoadTrip** is the solo operator + AI/model/agent workspace.

RoadTrip is where one human works with many intelligences. The user can bring in ChatGPT, Claude, Codex, local MLX, Ollama, custom agents, provider models, and BlackRoad’s native agents into one visible mission space.

RoadTrip is not CarPool. RoadTrip is solo. CarPool is where other humans join.

RoadTrip should feel like:
- a mission room
- a convoy room
- a multi-agent workspace
- a visible AI workbench
- the place where Alexa can work alone with any model or agent

RoadTrip should support:
- parallel AI threads
- agent roles
- model swapping
- local/remote model comparison
- task routing
- summaries
- memory capture
- visible reasoning artifacts without pretending private chain-of-thought is exposed
- handoffs to RoadCode, RoadView, RoadWork, RoadWire, and RoadMap

RoadTrip must not:
- become a generic chat app
- confuse solo work with group collaboration
- lose context between agents
- let agents act without CarKeys/Portia permissions
- claim autonomous execution without proof

**Primary integrations:**
- RoadOS for the workspace
- RoadCode for coding tasks
- RoadView for research/search
- RoadWire for durable notes
- RoadMap for task status
- RoadChain for receipts
- GloveBox for available capabilities
- CarKeys for tool access

**Core promise:**
“One human, many agents, one road.”

**Status:** Canon-ready (Level 4). Implementation planned.
