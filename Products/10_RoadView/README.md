# 10. RoadView

**RoadView** is search, discovery, and visible agent browsing.

It is where the 17,290 master index matters most. RoadView is not just “Google but BlackRoad.” It should route a query into the right lane, show sources, show agent browsing when needed, and let users decide whether their searches train their own agent or contribute to BlackRoad.

Search becomes a visible, receipt-backed, user-controlled process instead of opaque ranking fog.

**Primary integrations:**
- RoadOS command bar and launcher
- RoadTrip for agent-assisted search
- RoadBook and RoadWorld for content discovery
- RoadChain for search receipts and provenance
- GloveBox for capability-aware results

**Core promise:**
Find what you need, see how it was found, and keep control of your data and training.

**Status:** Canon-ready (Level 4). Implementation planned.
