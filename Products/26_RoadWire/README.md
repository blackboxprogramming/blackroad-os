# 26. RoadWire

**RoadWire** is asynchronous messaging, outside communication, email-like threads, long-term records, and non-immediate notes.

RoadTrip and CarPool should automatically note important work into RoadWire.

RoadWire differs from CarPool and RoadTrip because it is not the live room; it is the durable communication record.

**Primary integrations:**
- RoadOS for messaging surface
- RoadTrip / CarPool for automatic note capture
- RoadMap for status-linked threads
- RoadChain for important message receipts

**Core promise:**
Durable, searchable, receipted async communication that doesn’t get lost.

**Status:** Canon-ready (Level 4). Implementation planned.
