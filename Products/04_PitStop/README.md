# 04. PitStop

**PitStop** is the homework portal.

PitStop is tutoring, homework help, quizzes, lessons, practice, explanations, rubrics, learning paths, and teacher/student support. It is the place where a confused learner can stop, refuel, understand the next step, and keep going.

PitStop is not Roadie. Roadie is an agent. PitStop is the learning product.

PitStop exists because learning tools became paywalls, shame machines, PDF portals, LMS nightmares, and fragmented tutoring apps. PitStop should be forgiving, visual, structured, and calm.

PitStop should support:
- homework upload
- “explain this without making me feel dumb”
- step-by-step tutoring
- practice generation
- quiz generation
- visual explanations
- learning plans
- weak spot tracking
- teacher/classroom chaos support
- RoadBook source material
- BlackBoard visuals
- RoadView search
- Sophia tutoring

PitStop must not:
- become Chegg plagiarism sludge
- confuse tutoring with answer dumping
- shame the student
- use Roadie as the product name
- hide uncertainty when a source or answer needs checking

**Primary integrations:**
- Sophia as primary tutor agent
- BlackBoard for visual learning
- RoadBook for learning/publishing material
- RoadView for sourced search
- RoadMap for progress
- RoadChain for learning receipts if needed

**Core promise:**
“Pull over, understand it, keep going.”

**Status:** Canon-ready (Level 4). Implementation planned.
