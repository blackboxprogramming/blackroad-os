# 20. OfficeRoad

**OfficeRoad** is the visual meta office.

It is where humans work beside AI teammates in a visible office-like space. It is not just a dashboard. It is a spatial coordination layer: desks, rooms, tasks, documents, agent presence, and work context.

It makes AI coworkers visible instead of hiding them in chat boxes.

**Primary integrations:**
- RoadOS as the spatial shell
- CarPool for team rooms
- RoadMap for visible initiatives
- RoadWire for async coordination

**Core promise:**
See your team (human + AI) and work context spatially and clearly.

**Status:** Canon-ready (Level 4). Implementation planned.
