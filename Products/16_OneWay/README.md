# 16. OneWay

**OneWay** is the data sovereignty pipeline.

Data goes into BlackRoad, gets mapped, rotated, encoded, attached to durable identity/memory, and then sent back out in the form external providers need.

The point is to prevent OpenAI or any external provider from owning the long-term data layer.

OneWay is not just “export”; it is controlled one-way-and-back transformation with ownership preserved.

**Primary integrations:**
- RoadOS for data flows
- RoadTrip for agent data handling
- RoadChain for sovereignty receipts
- CarKeys for consent and permission on flows
- HighWay for secure transport

**Core promise:**
You stay in control of your data even when it leaves BlackRoad.

**Status:** Canon-ready (Level 4). Implementation planned.
**Risk:** High — data sovereignty and provider boundaries require careful design.
