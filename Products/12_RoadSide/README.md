# 12. RoadSide

**RoadSide** is the embeddable concierge/help surface.

It is the front-door chatbot for BlackRoad and for other companies. It answers, routes, escalates, explains, and hands off.

RoadSide is where a user says “help me” and the system figures out whether they need Roadie, RoadCode, RoadWork, CarKeys, Detour, or another product.

It should be the universal entry point that never leaves the user stranded.

**Primary integrations:**
- RoadOS as the main surface
- All products via handoff rules
- RoadTrip / CarPool for escalation to agents or humans
- RoadWire for durable help records
- RoadMap for tracking open issues

**Core promise:**
Help that actually helps and routes you to the right place without friction.

**Status:** Canon-ready (Level 4). Implementation planned.
