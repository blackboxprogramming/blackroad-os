# 09. RoadWorld

**RoadWorld** is drag-and-drop worlds, games, simulations, and playable creation.

It should make Roblox/Miniclip-style creation easier, but also go much bigger: historical survival simulations, world replicas, “drop into any time period,” decision comparison, worldbuilding, game mechanics, assets, monetization, and sharing.

If someone has a great game idea but cannot make the car work, RoadWorld should help them build it anyway.

**Primary integrations:**
- RoadOS shell
- BlackBoard for asset creation
- RoadShow for showcasing worlds
- RoadWork when monetization or business aspects appear
- RoadChain for provenance of creations

**Core promise:**
Anyone can build and share worlds and games without getting stuck on the hard parts.

**Status:** Canon-ready (Level 4). Implementation planned.
