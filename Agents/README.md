# Agents/

The 27 BlackRoad agents.

Agents are workers and roles. They request. Alexa approves. CarKeys gates. RoadChain records.

Roadie is Agent 02 — never a product.

See individual agent folders for roles, handoffs, permissions, and device assignments.

The canonical roster of all 27 agents lives in `Registry/agents.json` (validated by
`scripts/validate-agents.mjs` against `Registry/schemas/agent.schema.json`). That is
the single source of truth for agent id / number / name / role.
